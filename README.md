# 项目简介

## 核心功能
- 管理员管理模块：用户管理、商家管理、产品类型管理、数码产品管理、促销活动管理、系统管理、订单管理、个人中心

## 适用场景
- 数码产品销售平台
- 企业内部管理系统
- 教育机构项目案例

## 技术特点
- 架构：B/S、MVC、Web框架
- 开发环境：IDEA、JDK1.8、Mysql、Maven、Navcat
- 技术栈：Java、SpringBoot、Vue
